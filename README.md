Selamat datang di repositori website portofolio pribadi saya! Website ini dirancang sebagai wadah untuk menampilkan profil, keahlian, serta proyek-proyek web development yang sedang dan telah saya kembangkan.

---

## 📌 Deskripsi Singkat

Saya adalah seorang pelajar dan *web development enthusiast* yang memiliki ketertarikan mendalam di bidang teknologi informasi serta Rekayasa Perangkat Lunak (RPL). 

Melalui website ini, saya mengaplikasikan pemahaman struktur web yang rapi, antarmuka pengguna yang responsif, serta fitur interaktif dasar untuk menciptakan pengalaman pengguna yang nyaman dan modern.

---

## 🚀 Fitur Utama Website

- 🌓 **Dark Mode Toggle:** Pengubah mode tampilan gelap/terang secara instan menggunakan JavaScript dasar.
- 📱 **Fully Responsive Layout:** Tampilan otomatis menyesuaikan berbagai ukuran layar (Desktop, Tablet, dan Mobile).
- 🛠️ **Skill Badges Showcase:** Menampilkan keahlian serta *tools* yang dikuasai (HTML5, CSS3, JavaScript, Git/GitHub, CapCut).
- 📁 **Interactive Project Cards:** Galeri kartu proyek dengan efek interaktif (*hover elevation*).
- 📞 **Direct Contact Integration:** Tautan langsung interaktif ke WhatsApp dan Email.
- ⚡ **No Emoji Design:** Menggunakan vector icon (*FontAwesome*) untuk estetika visual yang bersih dan profesional.

---

## 💻 Tech Stack yang Digunakan

- **HTML5:** Struktur semantik dokumen web.
- **CSS3:** Styling layout, variabel warna CSS, animasi transition, Flexbox, dan CSS Grid.
- **JavaScript (ES6):** Manipulasi DOM untuk fungsi pengubah tema (Dark/Light Mode).
- **FontAwesome v6:** Icon set vektor untuk antarmuka visual.
